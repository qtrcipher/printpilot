# Project Audit — 2026-08-24

Four-facet audit (security, code quality, test quality, repo/docs hygiene) of
PrintPilot v0.1.0, read-only, with file:line evidence. Builds on
`security-audit-2026-08-17.md` (whose claims were re-verified after the D-pad /
on-screen-keyboard / recovery-guide additions).

## Verdict

Architecture and hygiene are well above average (clean pure/DI layering,
uniform IPC validation, real credential hygiene, honest docs whose numbers
re-derive exactly). But the audit found **one major functional defect that
likely breaks in-app navigation on the most common printer config**, plus a
broken mDNS rescan, a permanent-brick path on corrupt settings, and a dead
IPC channel that exposes keychain secrets to the renderer. All fixable in a
v0.1.1 pass.

## Critical

None.

## Major

1. **Navigation allowlist broken on default port 80** (security + test audits,
   independently). `src/main/index.ts:323` stores `allowedPrinterHost` as
   `host:80`, but `new URL(...).host` strips default ports, so
   `src/main/security.ts:34` never matches → in-printer navigations classify
   as `external` and are yanked to the system browser. Fail-closed (no escape),
   but defeats the feature. Invisible to CI because all fixtures/tests use
   non-default ports. Fix: normalize ports on both sides; add the two-line
   unit test that would have caught it.
2. **mDNS rescan silently dead after first stop.** `bonjour.destroy()` kills
   the socket permanently (`src/main/discovery-net.ts:42-47`) but `start()`
   reuses the instance, and every `discovery:start` stops first
   (`src/main/index.ts:265-270`) → second scan finds nothing, no error. Fix:
   fresh `Bonjour` per start.
3. **Corrupt `settings.json` bricks the app.** `createWindow()` awaits
   `loadSettings` uncaught (`src/main/index.ts:117`); `ConfigFileError` →
   unhandledRejection → no window, crash flag re-marked every launch, recovery
   notice can never display. Fix: quarantine corrupt file + boot with
   defaults + surface a notice.
4. **Dead `profiles:get-credential` channel returns decrypted PINs** to the
   renderer with no caller (`src/main/index.ts:306-308`,
   `src/preload/index.ts:121-122`). Pure attack surface. Fix: delete until an
   autofill feature needs it.
5. **OSK text probe mirrors password fields into shell DOM and keeps them**
   after disconnect (`src/preload/webview.ts:70-82`,
   `src/renderer/control.ts:315-317`; cleared only at next connect). Never
   reaches logs/diagnostics, but the app's one secret shouldn't linger. Fix:
   exclude `type=password` from the mirror (e2e asserts via a non-password
   field instead) and clear on close/blur.

## Minor (selected — full list in session)

- Gesture-less, unlimited `shell.openExternal` for guest off-host URLs
  (`index.ts:496-516`) — cap or confirm.
- `will-navigate` covers only the guest main frame; no subframe/webRequest
  block — hostile page could iframe external origins inside the window.
- `uncaughtException` swallowed, main keeps running in undefined state
  (`index.ts:475-477`).
- Dead channels/fields: `discovery:stop` (scan never actually stops),
  `nav:page-kind`, `keyboardScheme`/`mdnsEnabled`/`snmpEnabled` settings with
  no readers, `InputSource.kind` never read.
- Broken About link → `github.com/printpilot/printpilot` 404
  (`src/renderer/settings.ts:41`); same wrong owner in `electron-builder.yml:1`
  appId (decide consciously — changing appId later breaks upgrade identity).
- Retry button strands UI on loading splash if `connectPrinter` throws before
  the webview exists (`control.ts:354-358`).
- `NavEventBus.start()` accumulates handlers, no unsubscribe (latent
  double-dispatch trap).
- No host dedupe on profile add; read-modify-write races in both stores.
- `el()` helper duplicated in 4 renderer files; button-activation pattern
  duplicated dpad/osk.
- Stale docs: README status section predates release; `` `Ctrl+` `` broken
  inline code (README + CHANGELOG); electron-builder.yml "until Phase 4"
  comment; Dockerfile lacks `--publish never`; `.dockerignore` missing
  test-results/playwright-report; dead `allowScripts` in package.json
  (references electron-winstaller, not a dependency).
- Test gaps that matter (prioritized): default-port decideNavigation cases;
  frameset fixture + FocusRing degradation (real Canon RUI generations are
  frameset-based — mocks are frames-free); credential e2e on a saved profile;
  packaged-`--dir` adapter-loading smoke; gamepad pump test with firing fake
  `requestFrame`; e2e flake risks (300ms scan-window assertion, shared
  fixture ports, OSK stability flake).

## Good (verified, not assumed)

- `npm audit`: 0 vulnerabilities. `sanitizeNavEvent` complete + adversarially
  tested. Zero `innerHTML`/`eval` in src — untrusted strings via textContent.
- `handle()` IPC wrapper uniform; atomic config writes; deny-all permissions;
  no telemetry claim verified against code.
- Test counts in docs re-derive exactly (226 unit / 15 e2e); version/tag/
  changelog coherent; LICENSE matches metadata; release pipeline practices
  least privilege.

## Disposition

Fix in v0.1.1: Majors 1–5 + broken About link + stale README + docs nits.
Decide: appId owner change (do it before the user base grows), settings dead
fields (cut), openExternal gesture policy (cap + confirm).
Accepted/deferred: subframe webRequest hardening (note in audit), `el()`
dedup (house rule: no premature abstraction — revisit at 5th copy).
